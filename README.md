# Сметы

Веб-приложение для составления смет на React + Tailwind CSS в стиле iOS, рассчитанное в первую очередь на телефон.
Сервер не нужен: все данные хранятся в IndexedDB браузера (база `estimates`).
Сметы из старой версии (localStorage) переносятся автоматически при первом запуске.

- Список смет с поиском; свайп влево — Excel, копия, удаление
- Редактор сметы: название, валюта, позиции (наименование, ед. изм., кол-во, цена за ед., сумма), автосохранение
- Позиция редактируется в нижней шторке: крупные поля, цифровая клавиатура, единицы измерения кнопками
- Экспорт в Excel (`.xlsx`) с формулами сумм и итога; на телефоне открывается системное меню «Поделиться»
- Резервная копия (меню «⋯» в списке): все сметы сохраняются в один JSON-файл и восстанавливаются из него, в том числе на другом устройстве
- Светлая и тёмная тема по настройкам системы; можно добавить на экран «Домой»

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в один файл dist/index.html
```

Сборка кладёт в `dist/`:
- `index.html` — всё приложение в одном файле (на компьютере его можно открыть двойным кликом);
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — для работы без интернета и установки на экран «Домой».

## Телефон: установка и обновление

1. Выложите папку `dist` целиком на любой статический HTTPS-хостинг (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Откройте ссылку в Safari → «Поделиться» → «На экран Домой». После первого открытия приложение работает и без интернета.
3. Обновление: `npm run build` и загрузите новую папку `dist` **по тому же адресу**. При следующем открытии приложения
   с интернетом появится плашка «Доступна новая версия» → «Обновить». Сметы при обновлении сохраняются.

Офлайн-режим работает только при открытии по `http(s)://` — с диска (`file://`) браузеры service worker не поддерживают.

> Данные привязаны к браузеру и адресу, с которого открыто приложение. Очистка данных сайта в браузере удалит сметы — регулярно сохраняйте резервную копию.
